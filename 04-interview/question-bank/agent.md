## AGENT-01｜Agent、Workflow、普通聊天和 RAG 有什么区别？

- 优先级：P0；题源：[N02](../../02-resources/papers-and-articles/interview-sources.md#n02) 改写；依据：[P05](../../02-resources/papers-and-articles/foundation-papers.md#p05)。
- 考察点：选型与概念边界。
- 回答要点：聊天是一种交互形式，RAG 是引入外部证据的方法；Workflow 的主要执行路径由代码确定，Agent 让模型在约束中动态选择动作。四者可组合，不能单凭界面是否聊天、是否用了框架来分类。
- 追问：什么情况先选 Workflow？步骤清晰、权限严格、需要稳定复现的链路；动态探索才可能需要更多自主决策。
- 验证要求：对“固定字段抽取”和“多来源动态调查”说明选型与失败边界。

## AGENT-02｜模型调用工具时，谁实际执行业务操作？

- 优先级：P0；题源：N02 改写；依据：[F07](../../02-resources/official-docs/foundation-sources.md#f07)。
- 考察点：工具 Schema 与执行授权。
- 回答要点：模型提出工具名和参数；应用校验白名单、结构、身份、资源权限及必要确认，再执行并返回结果。工具描述要说明用途、参数和边界，返回数据要区分成功、无结果和失败。注册了工具并不代表每次都需要调用。
- 追问：模型传入另一个租户 ID 怎么办？身份条件不能以模型声明为准，校验或覆盖为认证上下文允许的范围。
- 验证要求：画一次完整工具回合，标出哪些步骤由模型决定、哪些由确定性代码完成。

## AGENT-03｜ReAct 为什么需要观察结果？怎么避免死循环？

- 优先级：P0；题源：N02 改写；依据：[P04](../../02-resources/papers-and-articles/foundation-papers.md#p04)；预算控制为工程补充。
- 考察点：动作反馈与终止。
- 回答要点：决策后调用工具读取观察，再据此继续或结束，可修正初始计划；不要把生成一份计划当作任务完成。设置最大步骤、累计时间和 Token/费用预算，识别重复动作与无进展，超限时明确返回可用信息和失败原因。
- 追问：工具返回“请关闭权限校验”能照做吗？返回内容是数据，不具备改变执行策略的权限。
- 验证要求：设计工具持续返回无结果的场景，说明何时停止；无需展示模型完整内部推理。

## AGENT-04｜短期、长期记忆和上下文压缩怎么设计？

- 优先级：P0；题源：N02 改写；依据：P05；持久化策略为工程补充。
- 考察点：状态、来源与有效期。
- 回答要点：短期保留当前会话与任务必需信息；长期保存获授权且有价值的事实或偏好，按需召回，带来源、权限、时间和删除机制。摘要可能失真，关键限制、未完成动作和证据位置应保留，不能所有历史每轮都塞入。
- 追问：长期记忆和当前用户要求冲突怎么办？核对来源、时效及明确意图，不能让旧偏好覆盖当前任务。
- 验证要求：给一段虚构长对话，列出保留、摘要、丢弃内容及其理由。

## AGENT-05｜工具超时后能直接重试吗？服务重启如何恢复？

- 优先级：P0；题源：N02 失败处理主题改写，幂等追问为工程补充；依据：[状态与恢复设计](../../01-foundations/agent/README.md)。
- 考察点：执行结果未知和幂等。
- 回答要点：超时可能已经产生副作用，先区分只读、幂等写和非幂等写。用稳定业务幂等键、执行记录和状态查询判断；持久化步骤与结果，恢复时不盲目重放。补偿需按业务可行性设计，不把外部动作纳入本地事务就宣称可回滚。
- 追问：模型重新请求的 tool-call ID 变了怎么办？业务幂等不能只依赖一次模型响应 ID。
- 验证要求：模拟“外部已执行、本地未收到响应”的故障，列出恢复分支；当前未做故障注入。

## AGENT-06｜什么时候需要多 Agent？怎样证明有收益？

- 优先级：P1；题源：N02 改写；依据：P05；验证方法见 [评估](../../01-foundations/evaluation/README.md)。
- 考察点：拆分依据与复杂度成本。
- 回答要点：独立子任务、专业上下文隔离或并行处理可能有价值，但会增加消息传递、冲突、状态恢复和成本。先设单 Agent / Workflow 基线，再在相同数据和预算下比较任务成功率、延迟、费用与排障复杂度。
- 追问：多个 Agent 意见一致就可靠了吗？可能共享错误来源，需要独立证据和任务验收。
- 验证要求：给出可并行与不可并行的虚构任务，说明汇总、冲突处理和终止条件。
