## 题源与使用方法

- **N01 / N02**：牛客社区可读帖的主题线索，详见 [题源卡与映射](../../02-resources/papers-and-articles/interview-sources.md)。作者陈述的面试真实性、公司归属及统计未独立核验。
- **工程补充**：结合 Java 主线自行设计，不能描述为社区原题。各题单独标注题源，答案依据链接回官方资料与原始论文。
- P0 / P1 是本仓库学习优先级；P0 优先练习，P1 后续扩展，不代表招聘市场频率。
- 所有题目当前掌握状态为 **未开始**；未进行模拟面试、评分或掌握度确认。

每题先独立讲 1～2 分钟，再对照回答要点。合格回答应包含“定义 → 链路或机制 → 取舍 → 如何验证”，不只罗列名词。追问后补一个可检查的例子；练习证据记入学习笔记。真实回答暴露的缺口再进入 [错题复盘](../mistake-reviews/README.md)，不要预造错误经历。
