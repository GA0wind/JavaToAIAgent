# Loan Platform Engineering Copilot

面向个人作品集的主实战项目框架。后续将围绕需求理解、工程知识检索和 Agent 工作流逐步定义与实现；当前不包含真实公司业务资料或预设业务规则。

- `requirements`：范围、用户故事、验收标准与非目标。
- `architecture`：系统边界、组件、数据流和关键取舍。
- `data-dictionary`：经授权且已脱敏的数据结构说明或合成示例。
- `ingestion`：知识采集、清洗、切分和索引流程。
- `retrieval`：检索、重排、引用和上下文构建。
- `agent-workflows`：工具、状态、编排和人工确认流程。
- `evaluation`：数据集、指标、基线、回归和安全评估。
- `deployment`：环境、配置、可观测性和发布说明。
