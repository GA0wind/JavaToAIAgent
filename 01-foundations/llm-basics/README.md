# LLM 基础

目标：解释一次模型调用在做什么，以及它为什么可能答错。关联第 1～3 周；[面试题 LLM-01～06](../../04-interview/question-bank/llm-basics.md)。资料整理日期：2026-11-05；个人掌握与实践状态：未开始。

## 核心概念

| 概念 | 定义与工程含义 | Java 经验对应 |
|---|---|---|
| LLM 与生成 | 常见自回归语言模型根据已有序列预测下一个 Token，逐步生成文本；生成目标不等于事实校验 | 类似返回不可信外部响应的远程服务，需要校验和降级 |
| Token / Tokenizer | Token 是模型处理的离散单位，可对应字、子词或字节片段；同一文本在不同分词器下数量可能不同 | 不能用 `String.length()` 直接当 Token 数 |
| Embedding | 将文本等输入映射成向量，用于相似度计算；相似不代表事实相同 | 类似可用于排序的特征表示，不是业务主键或数据库索引本身 |
| 上下文窗口 | 单次请求可处理的序列容量；输入消息、工具说明和输出预留共同占用预算，细则以提供商为准 | 类似请求容量约束，不是服务端自动持久化的 Session |
| Prompt | 发给模型的任务、约束、示例和资料；角色与内容的解释依赖模型及接口 | 版本化模板加请求参数；不能承担鉴权职责 |
| temperature / top_p | 前者调整采样概率分布，后者限制累计概率覆盖的候选集合 | 影响输出变化程度，不是“准确率开关” |
| 幻觉 | 生成流畅但缺少依据或错误的内容 | 外部服务结果可能语法合法、业务错误，仍需证据验证 |

Tokenizer 与模型基础见 [F01](../../02-resources/official-docs/foundation-sources.md#f01)、[F02](../../02-resources/official-docs/foundation-sources.md#f02)；采样概念见 [F03](../../02-resources/official-docs/foundation-sources.md#f03)。这些类比用于建立工程直觉，不表示模型和 Java 组件实现相同。

## Transformer 最小理解

输入通常经过分词、向量表示、位置相关处理和多层注意力 / 前馈网络。Self-Attention 让每个位置按内容关联其他位置；Q 表示查询，K 表示匹配键，V 表示聚合信息。缩放点积形式为 `softmax(QK^T / sqrt(d_k))V`，自回归生成还使用因果遮罩，避免读取未来位置。注意力本身不能表达完整顺序，因此需要位置相关机制。

原始 Transformer 使用 Encoder–Decoder；很多生成式 LLM 使用 Decoder-only，不能将两者结构等同。训练可并行处理已知序列的多个位置，逐 Token 生成仍有先后依赖。依据：[P01](../../02-resources/papers-and-articles/foundation-papers.md#p01)。

## Prompt、RAG 与微调

| 方式 | 改什么 | 适合解决 | 边界 |
|---|---|---|---|
| Prompt | 当前输入 | 任务说明、示例、输出约束 | 不能直接更新模型参数 |
| RAG | 检索出的外部证据 | 可更新、需要来源的知识问答 | 会受到资料质量和召回影响 |
| SFT | 通过监督样本训练参数 | 学习任务行为、风格和格式 | 有数据与训练成本，不保证记住每条事实 |
| LoRA | 冻结基础权重，训练低秩增量 | 以较少可训练参数适配任务 | 是参数高效微调方法，不是知识检索 |

LoRA 可写为 `W' = W + (alpha/r)BA`，其中 `W` 为 `d×k`，`B` 为 `d×r`，`A` 为 `r×k`，且 `r` 通常远小于 `d、k`。RAG 与微调可以组合。依据：[P02](../../02-resources/papers-and-articles/foundation-papers.md#p02)、[P03](../../02-resources/papers-and-articles/foundation-papers.md#p03)。

## 易错点

- 低温度不能保证事实正确，也不能笼统保证跨请求完全复现；部分模型不开放相同采样参数。
- 上下文越长不代表模型一定能利用全部证据；摘要可能丢失条件和否定语义。
- JSON 可解析只说明格式，不证明数值、权限或结论正确。
