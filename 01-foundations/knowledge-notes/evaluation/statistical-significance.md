# Agent 评测的统计不确定性

## 定义
统计不确定性描述有限评测样本和随机生成带来的分数波动。统计显著性是在给定检验假设下判断观测差异是否难以由随机波动解释，不等于业务重要或因果证明。

## 原理
报告样本量、成功率和置信区间；比较配置时尽量让它们运行相同任务并配对分析，可用配对 bootstrap 或适用的检验；重复随机种子，控制多重比较，并在独立样本复现。

## 为什么这样设计
Agent 输出和任务难度有差异，小样本的几百分点变化可能只是噪声。配对设计减少任务难度的干扰，复现避免偶然选中最佳结果。

## Java 工程关联
CI 结果保留逐例对照、模型/提示/索引版本、随机种子和环境；高风险类别有单独门槛。成本不足时将单次结果用于筛选假设，不宣布稳健提升。

## 高频面试题
1. **新版本 73% 对旧版 70% 就应切换吗？**答题要点：不必；看样本量、配对差异、区间、成本/风险及独立复现。
2. **为何优先配对评估？**答题要点：两个版本面对相同问题，减少任务难度差异造成的混淆。
3. **多重比较有什么风险？**答题要点：尝试很多配置后更容易偶然出现“显著”赢家，需调整门槛或独立验证。

## 自测
为两个检索方案设计同一问题集上的配对测试，并报告差异区间和主要退化样本。
