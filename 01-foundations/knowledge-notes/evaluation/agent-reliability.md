# Agent 可靠性指标：Pass@k 与 Pass^k

## 定义
Pass@k 表示同一任务运行 k 次时至少有一次通过，偏向探索能力上限；Pass^k 表示 k 次都通过，偏向重复交付的可靠性。两者回答不同问题，不能互换或只报对自己有利的指标。

## 原理
若各次成功独立且单次成功率为 p，则 Pass@k = 1 − (1 − p)^k，Pass^k = p^k。现实运行可能相关，故公式仅作假设模型；报告需声明 k、采样方式和任务是否可重置。

## 为什么这样设计
研究/创作可从多个候选中挑最好；退款、权限变更、支付和部署更关心每次都安全完成。成功定义还需加入安全/合规的一票否决项。

## Java 工程关联
在可重置沙箱做多次采样，保存每条轨迹；生产副作用不能“反复试到成功”。对比单次成功率、稳定性、风险事件、成本和人工介入。

## 高频面试题
1. **Pass@k 高为何不足以证明生产可用？**答题要点：它只要一次成功，隐藏其余失败及副作用风险。
2. **Pass^k 是否等于连续线上任务成功率？**答题要点：只有任务/独立性口径一致时才可解释；需说明同任务重复还是不同任务序列。
3. **如何选 k？**答题要点：按风险、预算、任务分布和独立性设定，不以 k 堆高结果。
