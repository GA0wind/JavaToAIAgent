# 评测集与回归测试

## 定义
评测集是由输入、期望结果/标签及必要判分规则组成的固定样本集合，用于比较模型应用版本并发现回归。它应代表目标任务和风险类型，而非只收集容易的示例。

## 原理
覆盖成功、边界、无答案、冲突、越权和格式失败案例；标注可回答性、相关证据和可接受结果。每次 Prompt、检索、模型或工作流变更后重跑并比较分组结果。

## 为什么这样设计
主观试用难发现系统性退化；固定数据集使优化可重复和可归因。样本不足或标签错误会让指标产生虚假信心，因此需版本管理与人工抽检。

## Java 工程关联
评测数据与合成/授权材料一起版本化，CI 可运行确定性解析、权限和契约测试；模型调用评测可分批跑，保护凭证并控制成本。

## 高频面试题
1. **怎么构建第一版评测集？**答题要点：从真实任务类型抽样并脱敏/合成，覆盖失败类别，人工标注证据和规则。
2. **每次模型输出都要完全相同吗？**答题要点：不一定；用指标和容忍区间比较，同时保留高风险用例硬门槛。
3. **如何避免数据泄漏？**答题要点：区分开发/回归/留出集，控制调参对留出集的反复使用。
