# Spring AI Tool Calling 组件

## 定义
Spring AI 的 Tool Calling API 将应用函数描述为模型可请求调用的工具，框架可将工具 Schema 发给模型、解析调用请求、执行本地回调并把结果回传。

## 原理
工具可通过注解方法、`ToolCallback` 等注册；ChatClient 将工具描述纳入请求；`ToolCallingAdvisor`/管理器驱动模型请求—工具执行—结果回注的迭代，直到模型给出最终响应或达到限制。

## 为什么这样设计
函数调用链由框架处理，业务方法保持普通 Java 服务；工具定义、序列化和执行接口可复用。框架能执行工具，但权限仍属于应用。

## Java 工程关联
工具参数需校验、鉴权、审计、限流和幂等；高风险工具只按调用动态提供并可加人工确认。处理工具异常时返回安全错误信息。

## 高频面试题
1. **工具 Schema 是否构成授权？**答题要点：否，它只描述能力和参数；执行时仍需服务端鉴权。
2. **为什么关注 ToolCallingAdvisor 顺序？**答题要点：决定记忆、日志等逻辑包围每轮循环还是只处理最终结果。
3. **何时自行驱动工具循环？**答题要点：需要逐步审批、预算监控、专有重试或中间事件时。

## 自测
在只读工具上记录模型调用、授权决定、执行结果和最终模型回复。
