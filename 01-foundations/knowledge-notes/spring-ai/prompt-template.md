# Spring AI Prompt 与 PromptTemplate

## 定义
Spring AI `Prompt` 表示送往聊天模型的消息集合及可选模型参数；`PromptTemplate` 用变量化模板构造可复用消息内容。它们负责表达请求，不是权限或业务校验组件。

## 原理
模板以变量映射填充输入，形成系统/用户等消息，再交由 ChatClient/ChatModel 发送；构建结果仍受具体模型的角色、格式和长度支持约束。

## 为什么这样设计
提示模板与业务代码分离，便于复用、测试和配置；显式变量有助于减少字符串拼接错误并跟踪 Prompt 版本。

## Java 工程关联
将模板文件纳入版本控制，变量 DTO 做必填和长度校验；将不可信用户输入作为数据插入，而不是拼接成系统指令。敏感原文禁止进入日志。

## 高频面试题
1. **PromptTemplate 相比字符串拼接有什么价值？**答题要点：变量管理、复用和可测试性，不自动保证安全或质量。
2. **模板里的变量能否包含用户指令？**答题要点：内容依旧是不可信输入，授权与提示层级不可混淆。
3. **如何管理 Prompt 变更？**答题要点：版本化、评测集回归、记录发布的模型和模板版本。
