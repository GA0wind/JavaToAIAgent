# Spring AI Evaluation API

## 定义
Spring AI Evaluation API 提供 `Evaluator` 抽象，以输入、上下文和生成响应为依据评估答案；框架提供如相关性或事实支持类评估器。

## 原理
构造 EvaluationRequest（用户问题、上下文、候选答案），Evaluator 返回 EvaluationResponse。某些实现调用另一模型作为评审，结果受评审模型和模板影响。

## 为什么这样设计
评估逻辑可从业务生成流程分离并用于集成测试或离线回归；共同接口便于替换评分策略。但框架示例评估器不是完整生产评测方案。

## Java 工程关联
把评估任务与线上请求隔离，使用固定数据集、模型/提示版本和人工标注校准；不要在高风险实时决策中依赖单次模型 Judge。

## 高频面试题
1. **Evaluator 返回通过是否证明答案正确？**答题要点：不是，取决于评估维度与评审可靠性，需人工校准。
2. **为何评审模型可与生成模型不同？**答题要点：可选擅长评估或成本更低的模型，并降低同模型自评偏差，但仍需校准。
3. **如何把评测接入 CI？**答题要点：固定样本、结果阈值、分组报告和差异审查，模型评测成本/波动要受控。

## 自测
用标注证据与回答构造评测请求，比较框架评估结果和人工结论。
