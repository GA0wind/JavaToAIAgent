# Agent 循环与停止条件

## 定义
Agent 循环是应用根据当前状态调用模型、处理工具请求、更新状态并决定继续或结束的控制流程。最小 Agent 通常由输入、模型决策、工具执行、结果回传和停止条件构成。

## 原理
每一步将状态交给模型，得到最终答复或动作请求；动作经过验证后执行，结果加入状态，再进入下一步。循环在完成、达到预算、用户取消、审批等待或不可恢复错误时结束。

## 为什么这样设计
把多步任务拆成可观测决策，模型能根据中间结果调整行动；但循环也放大延迟、成本和错误传播，因此需要明确边界而非无限自我调用。

## Java 工程关联
控制最大模型轮数、工具次数、墙钟时间和 Token 预算；每步产生 trace/span 和结构化状态。将可确定步骤写成普通服务逻辑，模型仅负责存在歧义的决策。

## 高频面试题
1. **Agent 的最小闭环是什么？**答题要点：观察/上下文、决策、受控动作、结果回注、停止判断。
2. **如何防止无限循环？**答题要点：轮数/时间/成本上限、重复动作检测、终止状态和人工接管。
3. **Agent 与 Workflow 区别？**答题要点：前者允许模型在运行中动态选择动作；后者预先定义主要控制流，可组合。
