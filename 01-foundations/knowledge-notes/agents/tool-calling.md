# Tool Calling（工具调用）

## 定义
Tool Calling 是模型输出一个符合工具契约的调用请求，由宿主应用解析、授权并执行工具，再把结果交回模型生成最终回复。模型提出调用意图，应用掌握执行权。

## 原理
应用向模型提供工具名、描述和参数 Schema；模型返回文本或结构化调用；宿主验证参数、身份和风险后调用后端函数；结果作为新消息回传，模型可继续调用或回答。循环须设置步数与时间预算。

## 为什么这样设计
模型擅长把自然语言映射到候选动作，确定性代码适合查询和执行。把二者分开能复用业务 API、加权限审计并限制副作用。

## Java 工程关联
工具是有输入输出契约的 Spring Bean/服务适配器；服务端重新校验，不将 Prompt 当授权。只读、幂等、可撤销和需审批操作分别分级。

## 高频面试题
1. **Tool Calling 和让模型直接访问数据库有何差异？**答题要点：模型只生成请求，由服务端校验并执行受限接口。
2. **如何避免重复副作用？**答题要点：幂等键、状态检查、事务边界和审批/补偿。
3. **模型返回参数就能执行吗？**答题要点：先校验 Schema、身份、范围、业务规则和风险级别。
