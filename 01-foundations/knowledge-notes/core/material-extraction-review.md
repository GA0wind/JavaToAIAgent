# 材料结构化抽取与人工复核

## 定义
材料预审抽取是从非结构化文档中提取字段、定位证据并提示缺项/冲突的辅助流程。它产生待核验结果，不直接替代业务规则判断或高影响决策。

## 原理
解析材料并保留页码/段落；模型按 Schema 抽取字段及原文证据；确定性代码检查必填、类型、格式、范围和跨字段规则；冲突、低证据和高影响项进入人工复核。

## 为什么这样设计
模型善于理解多种自然语言表述，代码善于稳定执行明确规则，人工适合处理歧义和高影响结论。职责分层比把所有判断交给一个模型更可审计。

## Java 工程关联
结果 DTO 区分提取值、证据、校验状态和复核状态；保存文档版本、模型/提示版本、规则版本和人工修改轨迹。模型自报置信度不能独立作为通过条件。

## 高频面试题
1. **为什么结构化输出后还要校验？**答题要点：Schema 只管格式，字段真伪/范围/业务关系需规则和证据检查。
2. **如何处理模型没找到字段？**答题要点：显式表示未发现/无法判断，避免补造；必要时进入人工复核。
3. **哪些步骤不应完全自动化？**答题要点：证据冲突、规则未覆盖、低质量材料及高影响决定。

## 自测
使用合成表单测试“完整、缺字段、格式错误、相互矛盾、无法识别”五类结果，并定义人工队列。
