# Transformer 与注意力机制

## 定义
Transformer 是以注意力和前馈网络为核心的神经网络架构。自注意力让序列中每个位置基于其他位置的表示，计算与当前预测相关的信息。

## 原理
输入 Token 先映射为向量并加入位置表示；注意力用 Query、Key、Value 计算位置间权重，再聚合信息；多头注意力并行学习不同关系，经过残差、归一化和前馈层堆叠形成深层表示。自回归模型使用因果掩码，避免看到未来 Token。

## 为什么这样设计
注意力能直接建立远距离依赖，训练时多个位置可并行计算；多头结构允许表达多类关系。代价是注意力计算和 KV 缓存占用随序列长度增长，长上下文有成本与延迟边界。

## Java 工程关联
不必手写算子；理解架构有助于解释 Token、上下文窗口、首字延迟、生成耗时和长上下文成本。服务侧用提示与检索控制输入，而不是无限扩长历史。

## 高频面试题
1. **自注意力做什么？**答题要点：计算序列内部相关性并聚合 Value 表示。
2. **因果掩码为何必要？**答题要点：训练自回归预测时屏蔽未来信息，保持训练和生成目标一致。
3. **长上下文为什么更贵？**答题要点：注意力计算和缓存随长度扩大；具体复杂度、实现优化依模型而异。

## 自测
解释 Query/Key/Value 和因果掩码，不依赖公式也能讲清楚信息流。
