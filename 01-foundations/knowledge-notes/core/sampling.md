# 采样参数与非确定性

## 定义
采样参数是控制模型从下一个 Token 候选分布中选取结果的设置，常见有 temperature、top_p、最大输出长度和停止条件。非确定性表示相同输入不保证每次得到完全相同输出。

## 原理
模型计算候选 Token 的 logits/概率。temperature 改变分布的尖锐程度，top_p 限制累计概率范围内的候选集合；具体实现由提供商决定。随机采样、模型服务变化或并行执行都可能带来差异。

## 为什么这样设计
任务对多样性需求不同：创意生成需要更多变化，抽取和分类通常希望稳定。参数提供控制旋钮，但不直接衡量事实正确性；低温也不能消除幻觉。

## Java 工程关联
记录实际发送参数和模型版本；只配置接口支持的选项。为重要业务流程结合结构化输出、规则校验、重试边界和回归评测，不把“temperature=0”宣传为绝对确定。

## 高频面试题
1. **Temperature 越低越准确吗？**答题要点：只影响采样分布，不等价于事实准确度。
2. **Temperature 与 top_p 都要调吗？**答题要点：先选一个控制变量做任务实验，避免无法归因；遵循服务商建议。
3. **如何提升可复现性？**答题要点：固定模型/提示/参数/输入并记录版本；仍需承认服务端可能更新。

## 自测
固定测试集比较不同采样配置的格式通过率、答案一致性和正确性。
