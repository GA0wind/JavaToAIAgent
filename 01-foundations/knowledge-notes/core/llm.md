# 大语言模型（LLM）

## 定义
大语言模型是以大规模文本或多模态数据训练、能根据上下文生成后续内容的模型。常见自回归 LLM 按序预测下一个 Token；“理解”是对其能力的工程化描述，不等同于人类意识或可靠事实库。

## 原理
文本经分词器转为 Token ID，模型结合上下文计算下一个 Token 的概率分布，再按解码策略选出一个 Token，循环直到停止条件。训练通常通过预测目标优化参数，推理时固定参数、逐步生成。

## 为什么这样设计
预测下一个 Token 提供统一、可扩展的训练目标，能从语言规律中学到可迁移的表示。生成接口通用，适合问答、摘要、改写和代码等任务；概率生成也意味着结果可能变化、遗漏或编造。

## Java 工程关联
把模型当作远程依赖：通过接口适配、超时、并发限制、错误分类、用量计量和降级管理。业务正确性仍由验证器、数据库和明确规则保证。

## 高频面试题
1. **LLM 每次回答是如何生成的？**答题要点：上下文编码、条件概率、逐 Token 解码、停止条件。
2. **LLM 为什么会幻觉？**答题要点：优化目标偏向生成合理续写，不天然等价于事实检索或验证；上下文、训练覆盖和解码都会影响。
3. **LLM 和传统分类器的主要差别？**答题要点：生成式通用接口与任务专用输出；仍需结构化约束、评测与业务校验。
