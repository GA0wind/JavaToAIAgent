# 幻觉与无依据回答

## 定义
幻觉是模型产生看似流畅、却错误、无证据或与给定来源不符的内容。可区分事实错误、来源不支持、实体/数值编造和误读上下文。

## 原理
生成目标偏向根据上下文续写合理序列，不要求每个命题先经外部事实校验。知识缺失、过时信息、歧义提示、检索噪声和过度自信都会诱发无依据回答。

## 为什么这样设计
LLM 的生成能力广，但开放式概率输出不能作为事实数据库。产品需将可回答范围、证据、拒答与人工升级设计为系统行为。

## Java 工程关联
回答关键结论绑定检索片段；将检索相关性与答案支持度分别评估；支持无答案出口；涉及高影响流程时交给确定性规则和人工复核。置信度自报不能代替外部验证。

## 高频面试题
1. **RAG 是否能消除幻觉？**答题要点：不能；检索可能漏、错或过期，生成仍可能误用证据。
2. **如何降低无依据回答？**答题要点：改善检索、限定来源、拒答规则、引用验证、结构校验和分层评测。
3. **怎样区分幻觉和检索失败？**答题要点：检查候选召回、上下文拼接、答案与证据支持度，分别定位。

## 自测
为问答评测集添加“资料中无答案”和“资料相互冲突”类别，定义正确拒答标准。
