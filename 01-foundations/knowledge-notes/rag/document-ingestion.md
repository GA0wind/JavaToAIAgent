# 文档解析与索引构建

## 定义
文档摄取（ingestion）是把原始文件转换成可检索记录的过程，包含读取、格式解析、清洗、切块、元数据提取、向量化和索引写入。

## 原理
原始资料先识别文本、表格、标题、页码和元数据，再按检索需求切成片段；片段和来源标识一起写入索引。更新或删除时需要能追踪文档版本、重建记录并清除旧片段。

## 为什么这样设计
把昂贵且可异步的预处理与在线问答解耦，便于批量重试、审计和变更检测；保留结构和来源可提高检索相关性与引用准确性。

## Java 工程关联
用后台任务/批处理执行解析与向量化，状态机记录待处理、成功、失败和重试；幂等键可由文档 ID、版本和处理配置构成。避免将原文未经授权发送到外部模型。

## 高频面试题
1. **增量更新如何避免旧索引残留？**答题要点：版本化、按文档 ID 删除旧片段、原子切换索引或维护可见版本。
2. **解析失败如何处理？**答题要点：隔离失败文件、保留错误类型和页码，不静默丢弃；支持重放。
3. **为什么保留页码和标题路径？**答题要点：用于过滤、上下文解释、引用回溯和定位原文。

## 自测
用合成 PDF 和 HTML 建一条可重跑的索引任务，验证重复运行与删除语义。
