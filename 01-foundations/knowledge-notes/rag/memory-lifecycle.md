# 用户记忆生命周期与审核

## 定义
用户记忆生命周期是跨会话个人信息从读取、候选提取、核验、保存、检索、更新到过期/删除的完整治理流程。它与任务执行中的短期状态不同，也不应把所有聊天内容永久保存。

## 原理
当前任务前加载相关记忆；任务后从证据提取候选；核验来源、冲突、隐私和适用条件；以局部变更更新存储；周期性整理重复/过期信息并保留版本或回滚能力。

## 为什么这样设计
个人记忆有助连续性，但错误、过时或敏感信息会在未来持续影响决策。候选—审核—更新的分阶段流程避免一次偶然对话直接改写长期事实。

## Java 工程关联
定义同意/用途、最小化、保留期限、删除和导出；记录来源和时间；冲突优先询问或采用可解释的优先策略。关键业务数据仍以权威系统为准。

## 高频面试题
1. **如何决定写入哪条记忆？**答题要点：有用性、稳定性、用户预期、来源可信和隐私授权共同判断。
2. **用户给出矛盾事实怎么办？**答题要点：保留时间/来源，标记冲突并澄清，不静默覆盖。
3. **长期记忆如何避免腐化？**答题要点：过期、去重、冲突检查、周期审核、可删除和回滚。

## 自测
设计从一次用户更正生成待审核记忆的记录结构，并覆盖拒绝保存、冲突和过期。
