# 引用与来源溯源

## 定义
引用是把生成结论关联到支持它的检索片段；溯源是保留从回答到片段、文档版本和原始页/段落的可追踪关系。展示一个链接不等于引用真实支持了结论。

## 原理
索引时保存稳定来源 ID、标题、版本、页码/偏移和片段内容；生成后返回引用 ID，并验证它来自本轮上下文。需要时做命题到证据的支持性检查。

## 为什么这样设计
用户能核对答案，工程师能定位解析/检索/生成故障，业务流程可审计。引用也会暴露证据不足，支持拒答而非编造。

## Java 工程关联
建立回答段落到 chunk ID 的数据模型，链接须服务端解析并执行权限检查；文档更新后引用指向版本化内容，删除内容要处理失效链接。

## 高频面试题
1. **模型给出的引用标识可信吗？**答题要点：不能盲信，必须验证它属于检索集合且链接权限有效。
2. **如何评估引用质量？**答题要点：检查正确性、覆盖率和证据是否支持对应主张，使用人工标注基线。
3. **仅有相似度分数够吗？**答题要点：相似不代表支持；需看具体证据与结论关系。

## 自测
设计答案段落与证据片段的结构化响应，验证错误引用 ID 会被服务端拒绝。
