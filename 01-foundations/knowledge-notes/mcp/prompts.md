# MCP Prompts

## 定义
MCP Prompt 是 Server 发布的可发现、可参数化消息模板，通常由用户在 Host 界面选择使用。协议统一发现与获取模板，不决定模型最终响应质量。

## 原理
Client 列出 Prompt 名称、描述和参数；用户选择后请求模板内容，Server 返回带角色和内容的消息，参数用于构造模板。Host 再将消息与其他上下文组合交给模型。

## 为什么这样设计
服务端可把专业任务提示作为可复用能力提供给多个客户端；让用户显式选择有助于理解当前采用的任务模板与输入范围。

## Java 工程关联
Prompt 不是权限策略，也不是自动执行的动作；填充参数前校验长度与内容，服务端模板更新需版本管理和评测。对其中注入的不可信文本仍做防护。

## 高频面试题
1. **MCP Prompt 由谁触发？**答题要点：通常面向用户显式选择，协议允许不同 Host 交互设计。
2. **MCP Prompt 与系统 Prompt 相同吗？**答题要点：不完全相同；MCP Prompt 是协议暴露的模板内容，Host 决定如何组合消息。
3. **Prompt 能保证模型遵从吗？**答题要点：不能，仍需输出校验、服务端授权和评测。
