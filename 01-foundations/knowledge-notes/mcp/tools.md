# MCP Tools

## 定义
MCP Tool 是 MCP Server 暴露给 Client 的可发现操作，描述名称、用途和输入 Schema，可由 AI 应用让模型选择调用。协议规定调用交互，不替服务端实现权限和业务逻辑。

## 原理
Client 通过 `tools/list` 发现工具和能力，向模型提供描述；模型提出调用后，Client 发送 `tools/call` 请求，Server 执行并返回内容或错误。Tool 清单可以依调用授权范围变化。

## 为什么这样设计
将操作以标准契约发布，多个兼容 Host 可复用；由服务端声明的 Schema 生成调用表单/模型参数，减少每个客户端单独适配。

## Java 工程关联
每次调用仍按身份检查、校验参数、限制副作用和审计；使用高风险工具时提供确认入口。MCP 工具目录不要默认暴露全部内部 API。

## 高频面试题
1. **MCP Tool 和 Java 方法有什么区别？**答题要点：方法是实现；MCP Tool 是经协议暴露的能力契约与调用入口。
2. **Schema 合法就可以执行吗？**答题要点：不可以，还要校验主体、资源范围、业务规则及风险。
3. **什么操作适合 Tool？**答题要点：边界清楚、输入输出稳定且能由服务端安全执行的动作；破坏性动作需审批/保护。
