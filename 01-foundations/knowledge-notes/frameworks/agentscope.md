# AgentScope

## 定义
AgentScope 是一个用于构建和运行 Agent 应用的开源框架，提供 Agent 抽象及相关对话、工具和编排能力。应以当前官方文档确认其支持范围和 API。

## 原理
应用通过框架定义 Agent、消息、工具与运行流程，再由框架协调模型交互和结果处理；具体组件、状态/执行模型可能随版本变化。

## 为什么这样设计
封装常用 Agent 开发工作，减少自行实现消息和工具循环的成本；采用前要评估项目语言、部署、状态管理、社区维护和生态连接。

## Java 工程关联
作为课程/岗位中的框架认知点，与 Spring AI、LangChain/LangGraph 做能力和语言栈对照；本项目如无明确需求，不为比较而额外引入依赖。

## 高频面试题
1. **框架选型看什么？**答题要点：语言栈、状态恢复、工具生态、安全、可观测、版本活跃度和团队能力。
2. **AgentScope 是否与 MCP 等价？**答题要点：不是，前者是应用框架，MCP 是互通协议层。
3. **如何验证框架适用性？**答题要点：用同一小型任务做 PoC，对比可控性、运维、质量和总成本。
