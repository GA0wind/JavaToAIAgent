# LangGraph

## 定义
LangGraph 是面向有状态、长运行 Agent 工作流的低层编排框架，以状态、节点、边、持久化和人工介入等概念显式表达执行过程。

## 原理
节点读取/更新状态，边决定后续节点，图执行器可支持循环、checkpoint、流式事件和暂停恢复。状态 Schema 与 reducer/并发更新语义需要明确设计。

## 为什么这样设计
简单链式调用难表达分支、循环和中途恢复；图结构提高复杂流程可见性和控制力，但也引入状态版本、持久化和编排复杂度。

## Java 工程关联
作为概念参照和 Python 生态要求，不取代本项目 Java 主线；用它评估长任务编排概念时需说明框架状态与业务数据库边界。

## 高频面试题
1. **Checkpoint 为什么重要？**答题要点：长任务可暂停/恢复、支持人工审批；副作用仍要幂等。
2. **状态图与普通工作流差异？**答题要点：Graph 面向共享状态和循环分支；具体能力依实现。
3. **何时值得采用 LangGraph？**答题要点：确有持久状态、复杂分支/循环、恢复或人工介入要求时。
