# RAGFlow

## 定义
RAGFlow 是开源 RAG 引擎/平台，强调文档理解、知识库构建、检索与带引用的问答，也提供可视化配置或工作流能力。它与通用 Agent 框架及底层向量数据库的定位不同。

## 原理
典型流程包含配置模型、建立 Dataset、导入并解析文档、切块/索引、设置检索与重排参数，再由 Chat/工作流调用检索结果生成回答并返回引用。

## 为什么这样设计
复杂文档解析和 RAG 管线需要连接多种模型、索引和流程；集成式引擎减少组装成本并提供可见配置。相应地要评估运维资源、数据驻留、权限模型、升级和可定制边界。

## Java 工程关联
可作为独立 RAG 服务评估并由 Spring Boot 调用；明确 API、认证、租户隔离、版本升级和故障边界。不要把平台自带引用或评分当成项目质量证明，需用自有数据集验证。

## 高频面试题
1. **RAGFlow 和 Spring AI 的区别？**答题要点：RAGFlow 偏集成式 RAG 引擎/应用平台；Spring AI 是 Java 应用开发抽象，通常由团队组合组件。
2. **如何决定自建还是用平台？**答题要点：比较解析质量、定制、权限、运维、成本、数据合规和迁移能力。
3. **重排能解决什么？**答题要点：对已召回候选排序，不能补回初始召回遗漏。

## 自测
用小型合成语料验证解析、混合检索、重排、引用和权限过滤，再评估服务资源要求。
