# LangChain4j

## 定义
LangChain4j 是面向 Java 的 LLM 应用开发库，提供模型集成、Embedding、向量存储、工具和 Agent 等能力。与 Spring AI 都服务 Java 生态，但编程抽象和集成方式不同。

## 原理
通过统一接口和 provider 集成连接模型与存储，再由应用组合 Prompt、工具和检索流程。具体功能覆盖和接口要以选定版本文档为准。

## 为什么这样设计
Java 团队可在熟悉语言中构建 AI 应用，复用现有后端体系；抽象能加速开发，也会带来依赖兼容和迁移成本。

## Java 工程关联
先按本项目已有 Spring Boot 目标使用 Spring AI；JD 或现有系统要求时，再做 LangChain4j PoC。比较模型覆盖、工具循环、RAG、测试、可观测和升级体验。

## 高频面试题
1. **Spring AI 与 LangChain4j 如何选？**答题要点：结合团队栈、能力覆盖、生态、版本成熟度和既有应用，不凭框架热度。
2. **统一抽象有什么代价？**答题要点：共同接口可能隐藏 provider 特性或滞后支持，需保留逃生通道。
3. **换框架是否可无成本？**答题要点：不能，Prompt、工具、检索、状态和评测都可能绑定抽象。
