# 超时、重试、降级与人工接管

## 定义
超时限定等待时长；重试再次执行可恢复失败操作；降级提供能力较弱但可用的替代路径；人工接管将不确定或高风险任务交给人处理。

## 原理
对错误分类后为幂等请求有限重试并退避；设置端到端 deadline、熔断/并发限制和预算。模型、检索或工具不可用时返回安全、可解释的退化结果。

## 为什么这样设计
LLM 与外部工具是慢且可能失败的远端依赖；无限等待或重试会耗尽线程、放大成本和副作用。人工路径能处理自动化不适合承担的决策。

## Java 工程关联
传播 deadline 至下游，按错误码决定是否重试；流式取消应停止后续工作。降级禁止悄悄放宽权限或无依据生成；记录接管原因和恢复状态。

## 高频面试题
1. **模型调用失败是否重试？**答题要点：只对可恢复错误限次重试，避免重复副作用并遵守总 deadline。
2. **降级时能否用旧缓存答案？**答题要点：要看时效、权限与来源版本，过期或越权缓存不能返回。
3. **何时人工接管？**答题要点：高风险、证据冲突、低把握、规则不满足或达到预算时。

## 自测
为超时、429、权限拒绝、模型不可用分别定义重试/降级/人工路径。
