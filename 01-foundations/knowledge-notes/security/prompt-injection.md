# Prompt Injection（提示注入）

## 定义
提示注入是攻击者将指令性内容放入用户输入、检索文档或工具结果，试图改变模型行为、泄露信息或诱发不当操作的风险。直接和经外部数据传递的间接注入都需考虑。

## 原理
模型可能难以可靠区分可信指令与不可信文本；恶意内容可要求忽略规则、调用工具或暴露上下文。提示分隔和系统指令能降低部分风险，但不能构成安全边界。

## 为什么这样设计
RAG 和工具连接扩大了不可信输入来源及可产生的影响。防护重点是减少可达数据和动作、在服务端验证，而不是仅靠模型识别恶意文本。

## Java 工程关联
工具最小权限、输入/输出检查、租户过滤、敏感字段屏蔽、人工审批和审计并用；评测集中加入间接注入及诱导工具调用样本。

## 高频面试题
1. **Prompt Injection 能否完全靠 Prompt 防住？**答题要点：不能保证，必须做纵深防御与执行层授权。
2. **RAG 文档为什么是不可信输入？**答题要点：内容来源可能被污染，模型会把它当指令解释。
3. **如何限制注入影响？**答题要点：最小权限、隔离上下文、工具参数校验、数据最小化和审批。

## 自测
在虚构知识文档中注入“泄露其他租户内容”指令，验证系统不扩大授权范围且能记录事件。
