## 与 Java 对照

| Python | Java 类比 | 必须注意的差异 |
|---|---|---|
| `list` / `dict` / `set` | `List` / `Map` / `Set` | 动态类型容器；可变对象可能被多处引用 |
| `None`、`is`、`==` | `null`、引用比较、值比较 | `is` 比较身份；值比较通常用 `==`；判空常写 `is None` |
| 类型标注 | 泛型与方法签名 | 标注通常不自动强制运行时校验，外部 JSON 仍需验证 |
| `with` | try-with-resources | 通过上下文管理器管理文件等资源 |
| 生成器与 `yield` | 惰性 `Iterator` | 边生产边消费，通常一次遍历，不能当成可反复读取的列表 |
| `venv` | 为项目隔离运行依赖 | 不是 Maven 本地仓库；不隔离操作系统，也不替你锁版本 |
| `async` / `await` | 异步 I/O、事件循环 | 协作式让出执行权；写了 `async` 不代表阻塞函数会自动异步化 |

## AI 工程常用数据形态

JSONL 每行是独立 JSON，适合逐条处理评估问题和响应。建议字段为 `id、question、expected_points、source_ids`，对缺字段、重复 ID 和解析错误明确报错。大文件使用逐行迭代，不要为了方便一次读入全部数据。这是本仓库练习设计，不是已建立的评估集。

依赖使用项目虚拟环境，调用 `python -m pip` 可明确安装目标解释器。固定依赖版本，并在复现记录中保存 Python 版本； `.venv` 不入库。示例命令应在实际选定解释器后执行，本文未创建环境。

## 易错点

- `b = a` 可能共享同一个可变列表；浅拷贝也不能隔离嵌套对象。
- `def f(items=[])` 的默认列表会跨调用复用；可用 `None` 作为默认值，在函数内创建列表。
- 同步网络请求放进协程仍会阻塞事件循环；并发调用需设置上限、超时与取消传播。
- 异步 I/O 并不等于 CPU 密集任务的多核并行；并发越大也不一定越快。
