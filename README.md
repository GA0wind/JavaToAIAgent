# Java to AI Agent Engineer

本仓库用于长期记录从 Java 工程师转型为 AI Agent 工程师的学习、实践、资料检索与面试准备过程。

## 使用方式

1. 每次开始前先阅读本文件、`AGENTS.md` 与 `00-roadmap/progress/README.md`。
2. 在 `00-roadmap` 维护目标、16 周计划和阶段进度。
3. 在 `01-foundations` 沉淀基础知识，在 `02-resources` 登记经过核验的资料。
4. 在 `03-projects` 开发作品集项目，并在 `04-interview` 进行面试准备与复盘。
5. 将过程笔记放入 `05-notes`，可对外展示的材料放入 `06-deliverables`。
6. 使用 `templates` 中的模板，并在 `sessions` 记录每次学习或模拟面试会话。

## 目录导航

- `00-roadmap`：目标、16 周计划与阶段进度。
- `01-foundations`：LLM、Python、Java/Spring AI、RAG、Agent、MCP、评估与安全。
- `02-resources`：教程、书籍、官方文档、论文与文章索引。
- `03-projects`：实战项目及其需求、架构、数据、实现、评估和部署资料。
- `04-interview`：岗位画像、题库、模拟面试记录与错题复盘。
- `05-notes`：学习笔记、技术决策与术语表。
- `06-deliverables`：简历、项目展示、架构图与演示材料。
- `templates`：可复用记录模板。
- `sessions`：每次协作会话的记录。

当前仓库仅搭建基础框架，内容将在后续学习和项目推进中逐步补充。
